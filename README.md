# 🛒 Amazon Frontend Clone

A clean, responsive, and interactive frontend clone of the Amazon website built using pure HTML5, CSS3, and Vanilla JavaScript.

## 🔗 Live Demo
[View Live Site](https://amazon-web-clone-v1.netlify.app)

## 🌟 Features
- **Responsive Layout:** Optimized navigation and display for desktop, tablet, and mobile devices.
- **Dynamic Slide-in Sidebar:** Smooth sliding side drawer for easy menu navigation.
- **Interactive Sub-Header:** Custom scrollable category selection bar.
- **Sign-In Modal:** Clean interactive login popup window.
- **Cart Counter & Back to Top:** Dynamic cart update counter and smooth page scrolling functionality.

## 🛠️ Tech Stack
- **HTML5:** Semantic site layout and structure.
- **CSS3:** Custom styles, Flexbox layout, and CSS Media Queries for responsiveness.
- **JavaScript (ES6):** Vanilla DOM manipulation and interactive UI event handling.
